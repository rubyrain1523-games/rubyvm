OS folders

No OS folder yet. Create one (for example "DOS"), then import the whole folder of OS files into it.

Tip: you can also drag files or a whole folder onto this panel. Files are stored in RubyVM (IndexedDB) and kept separate per OS folder. They are not yet visible inside the guest OS — only the chosen boot file is attached to the virtual machine. Empty subfolders can't be imported (the browser only lists files).

Computer configuration

The guest sees a wired network card (it can't see "wifi"). Needs a libv86.js that supports networking. Changes apply the next time you power on. Untested.

Each computer's selected image is saved in this browser's IndexedDB. Large images use browser storage, which may be cleared by ChromeOS storage cleanup. This prototype boots an image as a virtual CD-ROM; writable virtual hard disks and guest networking are later milestones.
